# LeafFS 界面翻译术语表（中 → 英）

用途：英文版页面（*.en.html）必须使用下列固定译法，保证全站一致。英文均为 AI 翻译，允许个别语法微调，但关键术语不许换词。

## 导航与页面
- 浏览 → Browse
- 预览 → Gallery（指图片/媒体浏览页与顶栏入口）
- 分类预览 → Gallery（页面内大标题用 Category view 时不改）
- 下载器 → Downloader
- 管理 → Admin
- 我的 → My Account
- 返回上级 → Back
- 返回管理 → Back to Admin
- 根目录 → Home
- 公共目录 → Public
- 我的目录 → My folder
- 我的账号（按钮/表头） → My Account

## 通用动词与状态
- 登录 → Sign In
- 游客访问 → Continue as Guest
- 退出登录 → Sign Out
- 上传 → Upload
- 下载 → Download
- 删除 → Delete
- 刷新 → Refresh
- 保存 → Save
- 应用 → Apply
- 取消 → Cancel（对话框/选择清理按钮一律 Cancel）
- 关闭 → Close（对话框）／Off（开关状态值）
- 新建文件夹 → New Folder
- 打开 → Open
- 全选 → Select All
- 取消全选 → Clear Selection
- 加载中… / 加载中... → Loading…
- 正在加载... → Loading...
- 暂无 → None / Empty（按语境：No files yet / No logs yet）
- 失败 → Failed
- 成功 → Success
- 已暂停 → Paused
- 已取消 → Cancelled
- 已完成 → Completed
- 正在…（进行时动词）→ -ing 形式（Signing in…, Uploading…）

## 角色
- 游客 → Guest
- 普通用户 → User
- 管理员 → Admin
- 超级管理员 → Super Admin

- 端口 → Port
- 连接 → Connection(s)
- 上限 → Limit / Maximum
- 会话 → Session
- 有效期 → Lifetime / Expiry
- 证书 → Certificate
- 密码 → Password
- 口令 → Password
- 用户名 → Username
- 游客模式 → Guest mode
- 开启 → On
- 关闭 → Off（仅开关值）
- 配额 → Quota
- 限速 → Speed limit
- 缓存 → Cache
- 缩略图 → Thumbnail
- 日志 → Logs / Log
- 服务器 → Server
- 默认 → Default

## 页面标题（<title>）
- 登录 → Sign In
- 我的 → My Account
- 文件传输 → File Transfer
- 下载器 → Downloader
- 预览 → Gallery
- 服务管理 → Admin
- 用户管理 → User Management
- 高级配置 → Advanced Settings
- 深度配置 → Deep Config
- 日志 → Logs

## 其它约定
- 英语表达简洁直接；中文长说明可适当压缩，但保留全部操作提示要点。
- 数字/占位符/文件名/路径原样保留，不翻译。
- 例外与不确定术语自行判断，但全站保持一致并在页面文件头注释标注。
