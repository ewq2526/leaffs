# 文档索引

四份文档，各管一件事，不要互相抄：

| 文件 | 讲什么 | 什么时候看 |
|---|---|---|
| `../README.md` | 这个系统是什么、怎么装、仓库怎么分 | 第一次接触 |
| `LEAFFS.md` | 应用能做什么：页面、接口、账号与分享 | 改应用行为 |
| `ARCHITECTURE.md` | 应用内部怎么运作：请求处理、会话、权限、上传、分享 | 改应用实现 |
| `TRANSLATION_GLOSSARY.md` | 界面上中英文的对应译法 | 改页面文案 |
| `UPSTREAM.md` | 应用与上游的关系、同步方式 | 同步上游 |

构建相关的三份在 `../mkimage/`：`BUILD.md`（怎么构建、每一步做什么、怎么验）、
`INSTALLER.md`（安装器：启动链、网页后端、两阶段脚本、排查）、
`PITFALLS.md`（踩过的坑）。

分发物在 `../for-distribution/`：只放许可原文、第三方声明与使用说明。

开发过程里的日志、过期草稿、被替换掉的英文版，都不留在仓库里 ——
它们在 `.work/archive/` 下按日期归档，需要时再翻。
