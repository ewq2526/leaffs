# LeafFS Translation Glossary (Chinese to English)

> English version. AI-translated from the Chinese original.

Purpose: English pages (`*.en.html`) and English documents must use the fixed translations below to keep the whole project consistent. English is AI-translated; minor grammatical adjustment is allowed, but key terms must not be reworded.

## Navigation and pages
- 浏览 → Browse
- 预览 → Gallery (the media/gallery page and top navigation entry)
- 分类预览 → Gallery (for an in-page heading, "Category view" is allowed)
- 下载器 → Downloader
- 管理 → Admin
- 我的 → My Account
- 返回上级 → Back
- 返回管理 → Back to Admin
- 根目录 → Home
- 公共目录 → Public
- 我的目录 → My folder

## Other conventions
- Keep English concise and direct; long Chinese explanations may be shortened while preserving all important instructions.
- Numbers, placeholders, file names, and paths are kept unchanged and are not translated.
- For exceptions and uncertain terms, decide consistently and note the choice in the page/file header comment.
