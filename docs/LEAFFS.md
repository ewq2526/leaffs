# LeafFS

局域网文件服务器，Python 实现，浏览器即用、无需客户端。除文件浏览/预览/上传/下载外，提供账号与游客访问控制、分享、URL 下载任务、HTTPS，以及一块只读的设备面板（状态与无线网络）。

面向使用与二次开发人员。架构与机制见 `ARCHITECTURE.md`。

## 功能

- **文件服务**：公共目录 + 每账号私有目录；浏览、上传、下载、目录打包下载、在线预览（图片/文本/视频/音频/PDF）。
- **分享**：自己的文件或文件夹分享为“公共分享”，也可经 `/p/<分享者>` 访问；可选访问码；引用而非复制。
- **访问控制**：用户 / 管理员 / 超级管理员三级；可选游客模式；配额与限速；登录限流与账号锁定。
- **下载任务**：HTTP/HTTPS 直链、磁力、种子、m3u8，服务端下载并入库；仅允许公网目标。
- **系统页** `/system`：主机、CPU、内存、温度、电池、按物理盘的容量与读写/繁忙度、服务状态、无线网络扫描与连接。**只对超级管理员开放**（普通管理员管账号与分享，不动设备配置）。
- **界面**：中英双语；亮暗主题 + 六种主色，按账号保存；文字可选中复制。
- **kiosk 形态**：`LEAFFS_KIOSK=1` 时全屏无边框、整页缩放到 125%（`LEAFFS_ZOOM` 可覆盖），用于接显示器的设备。

## 运行

- 环境：Python 3.13。
- 启动：项目根目录执行 `python -m leaffs`。源码运行时数据目录即项目根；打包运行时为主程序目录（`config/`、`shared_files/`、`.cache/`）。
- 端口：HTTP 8080、WebSocket 8081、证书提示页 8082（仅启用 TLS 时）。
- 首次进入：启动提示里的**本机一次性令牌**链接（`?leaf=`）以超级管理员身份登录，仅本机、仅一次。超管初始**没有口令**，进去先设一个；该链接不要外发。
- 外部程序：Linux 下用系统的 `ffmpeg`、`aria2c`、`openssl`（在 PATH 里即可）；Windows 打包版随附 `*.exe`，这些文件不进源码仓库。缺哪个，对应功能不可用（证书生成 / 下载器 / 缩略图），其余不受影响。
- 系统页需要 root 才能执行 `systemctl` 与 `wpa_cli`。

## 配置

| 文件 | 内容 |
|---|---|
| `config/server_config.json` | 主要运行配置 |
| `config/users.json` | 账号与口令哈希（PBKDF2-HMAC-SHA256），勿手改 |
| `config/downloader_config.json` | 下载器配置 |

管理入口：`/admin`（游客模式、配额、限速、连接上限、日志）、`/admin/advanced`（端口、TLS、缓存、上传与预览上限、ZIP 方式）、`/admin/deep`（哈希参数、缩略图、会话有效期、访问日志）、`/me`（本人信息、设备管理、改密、语言与主题）、`/system`（设备面板，超管）。

## HTTPS

不向系统信任库安装任何根证书。证书来源按优先级：配置里显式指定的 `tls_cert`/`tls_key` → 已存在的 `config/selfsigned.crt` 与 `selfsigned.key` → 首次启用 TLS 时自动生成自签证书。浏览器会提示不安全，属正常；8082 页面用通俗文字说明，不做自动跳转。

## 已知限制

1. 面向**可信局域网**。公网使用需正式证书、关闭游客模式、强化口令；程序不含 WAF、验证码、2FA。
2. 默认整机 256 连接、每设备 HTTP 20、WebSocket 8，超限直接拒绝不排队；空闲连接 15 秒断开，单请求内停滞 120 秒断开。均可在管理页调整。
3. 游客模式下公共目录对网内任何人可读，游客可上传但不能覆盖/删除/建目录。
4. 文件名含路径分隔符、控制字符或 Windows 保留名会被拒绝；HTML/SVG 按纯文本或下载返回，不内联执行。
5. 数据是文件 + JSON，无数据库；并发写有原子写保护，仍建议定期备份 `config/` 与 `shared_files/`。
6. 改无线网络会短暂断开当前 Wi‑Fi；新网络连不上时自动回滚到原来那个。
7. 日志为基础运行日志，不含审计能力；不记录口令与会话令牌。

## 忘记口令

登录后到管理页改；忘记了就在本机重启服务，用启动提示里的本机令牌链接以超管身份进入再改，无需删文件。

## 开发

- 入口 `leaffs/app.py`（`leaffs/leaffs.py` 是兼容垫片）；按域分目录：`auth`、`files`、`share`、`config`、`dl`、`web`、`server`、`system`、`utils`。
- `system/` 是只读采集与无线控制：`host.py` 读 `/proc`、`/sys`、`systemctl`，`wifi.py` 走 `wpa_cli`，`api.py` 组装响应；鉴权统一在 `server/handler.py` 的分派层判定，不在处理函数里各判一遍。
- 页面中英双份，英文文件以 `.en.html` 结尾；语言判定顺序为 cookie `leaf_lang` → 账号偏好。英文为 AI 翻译，术语见 `TRANSLATION_GLOSSARY.md`。
- 注释中英双语，只留有信息量的。
- 本项目高度依赖 AI 辅助开发（主要模型 DeepSeek V4 Flash）。
