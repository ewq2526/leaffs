# LeafFS

局域网文件分享/下载服务器，Python 3.12 实现。部署于局域网内一台机器，同网络其它设备用浏览器访问服务地址即可浏览、预览、上传、下载文件。提供账号与游客访问控制、HTTPS/TLS、URL 下载任务等功能。使用方无需安装客户端。本文面向使用与二次开发人员。

## 1. 功能

- 文件服务：公共目录与每账号私有目录；浏览、上传、下载、目录打包下载、在线预览。
- 文件分享：把自己目录里的文件与文件夹分享出去，分享内容作为“公共分享”出现在浏览页，别人也可通过分享页 `/p/<分享者>` 访问；可给分享设置访问码。分享是引用而非复制，文件始终留在原位置。
- 访问控制：用户、管理员、超级管理员三级角色；可选游客模式；配额与限速。
- 下载任务：HTTP/HTTPS 直链、磁力、种子、m3u8，由服务器下载并入库。默认仅允许公网目标，访客默认不可用；aria2c（磁力/种子所用进程）异常退出时会自动重启。
- 其它：二维码登录、本机免密令牌、HTTPS 自签证书自动生成、连接与并发上限可调、登录限流与账号锁定。
- 多语言：界面提供中文与英文。语言在“我的”页选择，选择同时保存到登录账号（服务端）；浏览器带语言 cookie 时以 cookie 为准。英文版为直写页面文件（`*.en.html`），服务端据此返回，无英文文件时回退中文。英文内容为 AI 翻译（可能存在差异），统一译法见 `TRANSLATION_GLOSSARY.md`。
- 界面外观：支持更换主题主色（蓝/绿/紫/橙/红），亮色与暗色各有一套背景配色；主题色在“我的”页设置并按账号保存。
- 安卓版：同一套服务端与网页也可跑在安卓手机上（App 启动后，同一 WiFi 或热点下的设备用浏览器访问手机地址）。构建方式与目录结构见 `android/README.md`。

## 2. 运行

- 环境：Python 3.12。
- 启动：在项目根目录执行 `python -m leaffs`。
- 随附二进制：`leaffs/` 内的 `openssl.exe`、`aria2c.exe`、`ffmpeg.exe` 及 OpenSSL 运行库（`libssl-3-x64.dll`、`libcrypto-3-x64.dll`、`zlib1.dll`）**不随源码上传**（见 `.gitignore`）。源码运行需要这些功能时，请在本机放置对应文件或安装系统版本；缺失时相应功能不可用（如自动生成证书、下载器、缩略图），其余功能不受影响。
- 服务端本机登录：启动提示中的本机一次性令牌链接（含 `?leaf=`）会以默认超级管理员身份自动登录，令牌一次性、仅本机可用，用于首次进入管理界面并修改默认口令；请勿把该链接发送给他人。
- 默认端口：HTTP 8080，WebSocket 8081，证书提示页 8082（仅启用 HTTPS 时启动）。
- 首次登录使用默认管理员账号 admin，请尽快修改口令；仍为默认口令时管理界面会提示改密。
- 运行数据目录：源码运行时为项目根目录，打包运行时为主程序目录。运行产物含 config、shared_files、.cache。

## 3. 配置

- `config/server_config.json`：主要运行配置。
- `config/users.json`：账号与口令哈希（PBKDF2-HMAC-SHA256），勿手改。
- `config/downloader_config.json`：下载器独立配置。
- 管理页入口：
  - 管理页 `/admin`：游客模式、配额、限速、连接上限（整机、每设备、WebSocket）、连接用户、日志预览。
  - 高级配置 `/admin/advanced`：端口、TLS、缓存、上传与预览大小、ZIP 打包方式与上限。
  - 深度配置 `/admin/deep`：密码哈希迭代与盐长度、缩略图参数、会话有效期、访客写入与下载器开关、访问日志、连接空闲超时、证书提示页监听地址、兼容存档。
  - 用户信息 `/me`：当前账号与角色、空间用量、当前设备与登录设备管理（退出其它设备）、自助修改密码、界面语言与主题色设置、服务器地址复制。
- ZIP 打包默认全流式（边压缩边发送，无临时磁盘占用）；可在高级配置切换为先打包后发送（带总大小，但大文件会占用临时磁盘）。

## 4. HTTPS 与证书

- 本程序不向系统信任库安装任何 CA 或根证书，不提供一键信任机制。
- 服务器证书来源，按优先级：
  1. `config/server_config.json` 显式配置的 `tls_cert` / `tls_key`；
  2. 已存在的 `config/selfsigned.crt` 与 `selfsigned.key`；
  3. 两者皆无且启用 TLS 时，首次启动自动生成随机自签服务器证书并写入 config，此后直接复用。该证书不生成 CA，不安装信任库。
- 仅当显式证书不可用且自动生成也失败时，程序拒绝以明文方式启动。
- 自签证书在浏览器中会提示不安全，属正常现象。证书提示页 8082 用通俗文字说明该现象。该页**不做任何自动跳转** —— 按页面上的按钮自行前往主站。

## 5. 已知限制与注意事项

1. 本软件面向可信局域网设计，不建议直接暴露到公网。公网使用需自行配置正式证书与域名、关闭游客模式并强化口令管理；程序不提供 WAF、验证码或 2FA。
2. 登录状态会保存下来，服务重启后无需重新登录；登出、踢下线、修改口令与删除账号都会立即生效。登录有限流与锁定：同一出口 IP 每分钟最多 30 次；同一账号连续失败约 6 次锁定 10 分钟；账号级 12 次每 15 分钟全局锁定；另有一层全站范围的登录限速（**本机访问不受它限制**），用于在出现大量登录尝试时保护服务。同一 NAT 或代理后的多台设备共享出口 IP，会共享限流计数。
3. 游客模式开启后，公共目录对网络内任何人可读，游客可上传新文件但不能覆盖、删除或建目录。请勿把私密文件放入公共目录。
4. 上传文件名包含路径分隔符、控制字符或 Windows 保留名时会被拒绝。HTML、SVG 等脚本类文件预览时按纯文本与下载方式返回，不内联执行；请勿依赖此机制存放并分享可执行或含脚本内容。
5. 并发与资源：默认整机最多同时 256 个连接，每设备 HTTP 最多 20 个，每设备 WebSocket 最多 8 个；超限连接立即被拒，不排队。连接复用生效后，**空闲等待下一个请求**的连接会在“空闲连接超时”（默认 15 秒）后断开；而**一次请求内部**收发停滞超过“连接空闲超时”（默认 120 秒）也会断开。以上可在管理页调整，保存后立即生效。
6. 下载器默认仅允许公网目标，回环、内网与云元数据等地址被拦截。
7. 密码最小 8 位仅对新设与修改生效，存量弱口令不会被强制升级。
8. 日志为基础运行日志（可关闭），不含完整审计能力；日志不记录口令与会话令牌。
9. 数据以文件与 JSON 存储，无数据库。并发写有原子写保护；极端场景仍建议定期备份 config 与 shared_files。

## 6. 忘记管理员口令

- 常规修改：登录后在 管理 页进入 用户管理，选择账号修改口令（改密后该账号旧会话下线）。
- 忘记口令时：**依赖服务端本机令牌登录**。在本机重启服务，打开启动提示中的本机一次性令牌链接，即以默认超级管理员身份登录，随后在 用户管理 修改口令即可；无需删除任何文件。令牌每次启动重新生成、仅本机可用。

## 7. 开发说明

- **架构与机制说明见 `ARCHITECTURE.md`**（英文版 `ARCHITECTURE.en.md`）：分层与依赖方向、请求数据流、认证/权限/文件/分享/配置/下载器各域的关键机制，以及“为什么这么设计”。
- 主入口 `leaffs/leaffs.py`（兼容垫片，指向 `leaffs/app.py` 的启动装配）；服务端代码按域分目录：`auth`（账号与会话）、`files`（文件）、`share`（分享）、`config`（配置）、`dl`（下载器）、`web`（页面渲染）、`server`（HTTP/WebSocket/推送/TLS/主机工具）、`utils`（通用工具）。
- 数据目录规则：源码运行等于项目根，打包运行等于主程序目录。
- 主要配置键：`http_port`、`ws_port`、`tls_trust_port`、`tls_enabled`、`tls_cert`、`tls_key`、`trust_bind_host`、`guest_mode`、`guest_public_write`、`downloader_guest_allowed`、`max_total_conns`（默认 256）、`max_conn_per_ip`（默认 20）、`ws_max_conn_per_ip`（默认 8）、`io_idle_timeout_secs`（默认 120）、`keepalive_timeout`（默认 15）、`zip_max_files`、`zip_streaming`（默认 true）、`pbkdf2_iterations`、`salt_length`、`access_log`。
- 账户口令哈希格式：迭代次数、Base64 盐、Base64 摘要，以 $ 分隔。
- 内置外部程序：`openssl.exe`、`aria2c.exe`、`ffmpeg.exe`，用途与许可见第 8 节及第三方声明文件。
- 携带失效会话 Cookie 的 API 请求在路由前统一返回 401；`/api/qrlogin` 等匿名路径在豁免名单内。
- 页面文字均可选中复制；二维码颜色随亮暗主题变化。
- 多语言实现：页面同一目录放置中文版与英文版文件，英文文件以 `.en.html` 结尾。语言判定顺序：请求 cookie `leaf_lang` 优先；无 cookie 时使用该登录账号保存在服务端（users.json）的语言偏好，供软件自带窗口等无痕会话重启后恢复。语言选择器在“我的”页，切换会写 cookie、保存账号偏好并刷新。英文由 AI 翻译，术语一致性由 `TRANSLATION_GLOSSARY.md` 保证。
- 注释规范：代码注释统一为**中英双语**（一行中文说明 + 相邻一行英文，或同句双语），仅保留有信息量的注释，删除重复代码/过时/无意义注释；英文部分可标注 AI 翻译。全库正在按此规范分批清理。
- AI 编程辅助：本项目为高度 AI 辅助开发的项目，主要使用的模型为 DeepSeek V4 Flash；说明见 `THIRD_PARTY_NOTICES.md`。
