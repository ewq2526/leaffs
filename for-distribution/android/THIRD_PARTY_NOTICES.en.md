## Current Obligations and Practices

- **License texts**: the license texts of every component above are provided in the `licenses/` directory beside this notice, and inside the APK under `assets/licenses/`.
- **MPL-2.0 components (GeckoView, certifi)**: as required by MPL-2.0 section 3.2, the official source location of each is given above in the "Upstream / official source" column. This project has not modified these components, so no further source-disclosure obligation arises.
- **No GPL/LGPL components**: the Android build contains **neither** aria2c **nor** ffmpeg (both ship with the desktop build only), so there is no GPL-family obligation to provide corresponding source.
- **Modification obligation**: this project has not modified any component listed above. Should that change, corresponding source or a written offer to obtain it will be provided as the component's license requires.
- **Origin of the Python dependencies**: installed by Chaquopy as wheels from its official mirrors; this project has made no changes to them.

## Verification Record — 2026-09-21

This notice is new in this round — previously the Android build had **no third-party notice at all**, and the desktop `THIRD_PARTY_NOTICES.md` barely overlaps with what is actually packaged, so it could not be reused.

Method: the APK build artifacts `chaquopy/requirements-common.imy` and `chaquopy/bootstrap.imy` (both zip containers, each component carrying its own `dist-info` and license text) were read directly to extract component names, versions and license texts — their byte sizes match the same files inside the APK **byte for byte** (2851386 / 599781), confirming the list reflects the shipped contents; application-layer and transitive dependencies were read from the APK's `META-INF/*.version` marker files and top-level library markers (`play-services-*.properties`, `kotlin/`, `kotlinx_coroutines_*.version`); the license types of GeckoView and Chaquopy were confirmed through upstream channels (Chaquopy's official announcement and the GitHub API both state MIT).
